Visual event-driven programming for Godot 4

Build game logic with event sheets — conditions and actions in a spreadsheet-like grid — inspired by Clickteam Fusion 2.5 and Construct. This enhanced fork focuses on stability, clearer UX, and a richer set of built-in providers.

Overview

FlowKit lets you create gameplay without writing full scripts: pick a node, choose an event (On Process, On Body Entered, On Ready…), add conditions, then stack actions. Sheets are stored as .tres resources and run automatically when the scene starts.

Key Features

🎯

Event Sheet System

Events, conditions, actions, groups, comments, and branch blocks (if / else / repeat).

🔌

Node Targeting

Bind logic to any scene node or the global System object — with search and recent items.

📦

Extensible Providers

Drop-in actions, conditions, and events as GDScript files — auto-discovered by the registry.

⚡

Runtime Engine

Autoloads load sheets by scene UID, support multi-frame waits, and isolate concurrent actions.

💾

Project-Local Sheets

Sheets save under res://flowkit/event_sheets/ with human-readable names (legacy paths still load).

🧪

Expressions

GDScript expressions with node, scene_root, system, delta, sheet vars (s_score), and current for For Each.

📋

Sheet Vars & Subsheets

Typed sheet vars, reusable subsheets with parameters (p_name, Call Subsheet ArgsJson, For Each + current.

🧩

Multi-Behaviors

Stack multiple behaviors per node (inspector + Apply/Remove Behavior actions). Legacy single-slot meta still loads.

★

Favorites & Filter

Star events/conditions/actions, Ctrl+F sheet filter, OR condition groups with visual AND/OR separators.

Getting Started

Installation

  1. Clone github.com/slagusev/FlowKit or download a release
  2. Copy addons/flowkit into your project’s addons/ folder
  3. Enable the plugin: Project → Project Settings → Plugins
  4. Open the FlowKit main screen (or panel) and create a sheet for the current scene

First sheet

  1. Open a scene, switch to FlowKit
  2. Add Event → pick a node → pick an event
  3. Optional: Add Condition
  4. Add Action → configure expression inputs
  5. Sheets auto-save to res://flowkit/event_sheets/<SceneName>_<uid>.tres

Requires Godot 4.5+. Tested with Godot 4.6. Demos live under addons/flowkit/demos/.

Architecture

Dual-mode design: editor authoring + runtime execution.

Editor

  • Main screen event sheet UI
  • Modals for nodes / events / conditions / actions
  • Undo stack, clipboard, auto-save
  • Provider generator & export manifest

Runtime

  • Autoloads: FlowKit + FlowKitSystem
  • Scene detection by resource UID
  • Signal events + polled events
  • Branches, behaviors, multi-frame actions

Event sheet (simplified)

FKEventSheet
  events / groups / comments
    FKEventUnit
      conditions[] → FKConditionUnit
      actions[]    → FKActionUnit (may nest if/else/repeat)

Built-in Providers (highlights)

Events

  • On Ready, On Process, Physics Process
  • Input: key, mouse, actions
  • Area2D body entered / exited
  • Timer timeout, Button pressed

Conditions

  • Key / action / mouse state
  • Is on floor / wall / ceiling
  • Distance less than, random chance
  • Compare variables, FPS, pause

Actions

  • Print, set variable, wait (sec/frames/input)
  • Move & slide, velocity, tween position
  • Create instance, queue free, look at
  • Define / call function, play animation

Custom providers: add a .gd under addons/flowkit/actions|conditions|events/ extending FKAction / FKCondition / FKEvent.
